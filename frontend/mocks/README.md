# Фронтенд с тестовым API

Из каталога `frontend` запустите `npm run dev:mock` и откройте http://localhost:5173.
Vite обновляет интерфейс через HMR. Docker, Go API, PostgreSQL, runner и сессия hh.ru не нужны.
Обычный `npm run dev` сохраняет проксирование настоящего API, production-сборка не включает моки.

Мок обслуживает все API-маршруты приложения. Анализы и вакансии хранятся в памяти процесса Vite,
поэтому сохраняются при обновлении страницы и HMR. Остановка Vite сбрасывает изменения.
Создание анализа имитирует очередь, сбор и завершение за 12 секунд. Сохранённые примеры
`running` и `queued` остаются в этих состояниях, чтобы можно было проверять их интерфейс.
Удаление скрывает анализ вместе с вакансиями, восстановление возвращает тот же снимок.

В истории есть десять тестовых анализов: все семь статусов, даты сегодня, вчера,
3 и 5 дней назад, на прошлой неделе и в прошлом месяце, а также пустой результат.
Отчёты содержат пересекающиеся форматы работы, семь городов, девять компаний,
навыки и требования с подтверждающими фрагментами, разные зарплаты, пропуски и нули откликов.
Все вакансии и показатели вымышлены и помечены как тестовые. Ссылки вакансий открывают
поиск hh.ru. Курсы валют фиксированные и предназначены только для тестирования.
Поисковые фильтры сохраняются в анализе как выбранные условия; содержимое выборки
генерируется для проверки интерфейса, без имитации поискового движка hh.ru.

Сбросить данные можно из консоли браузера, затем обновить страницу:

```js
await fetch('/api/mock/reset', { method: 'POST' });
```

Для пустой истории:

```js
await fetch('/api/mock/reset', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ scenario: 'empty' }),
});
```

Проверка контрактов и изменения состояния: `npm run test:mock`.
